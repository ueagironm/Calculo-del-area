# Calculo-del-area

## Descripción
Este es un pequeño programa escrito en Python diseñado para calcular el área de diferentes figuras geométricas. 

## Requisitos
Para poder ejecutar este código, necesitas tener instalado:
* [Python 3.x](https://www.python.org/downloads/)

## Cómo usarlo
1. Clona este repositorio en tu computadora o descarga el archivo `.py`.
2. Abre una terminal.
3. Ejecuta el siguiente comando:
   ```bash
   python "Calculo de area.py"
